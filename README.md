# AeroCalc DFM

Welcome to the **AeroCalc DFM** project repository! This application is designed to analyze and calculate aerodynamic parameters using DFM principles. 

## 🚀 Overview

AeroCalc DFM is an open-source project aimed at streamlining Design for Manufacturing (DFM) analyses within aerodynamic applications. The monorepo contains various services including the core web app, API gateway, and DFM analyzer tools.

## 🤝 Open for Collaboration

We strongly believe in the power of open source! This project is **open to collaboration**, and we welcome contributions from developers, aerodynamicists, and designers alike.

## 📦 Project Structure

- `apps/aerocalc-web` - The main web application.
- `apps/dfm-analyzer-web` - The DFM analysis specific application.
- `apps/api-gateway` - The backend API gateway service.

## 🛠️ Tech Stack

- **Turborepo** for Monorepo management.
- **Next.js** / **React** for frontend web apps.
